# P17 cinematic music: CC0 candidates

Curated 2026-11-11 by the asset-curator. Nothing was downloaded and no game file was edited. Every row below was read on its own Freesound page (the licence line, duration, format and tags are quoted from that page). **No clip has been listened to**: "fit" is judged from title, tags and the author's description, so the owner should audition before choosing.

All entries are **Creative Commons 0** as stated on the sound page. No CC-BY extras are offered (none were verified and none were needed).

Sources: Freesound only. OpenGameArt blocked automated page reads (HTTP 403), so no OpenGameArt candidate is listed because none could be verified.

Format notes: any of these can be converted to 48 kHz 16-bit WAV in the audio prep step. The `szegvari` files are **6-channel, 96 kHz, 24-bit, about 135 MB each**; they would need a stereo downmix.
